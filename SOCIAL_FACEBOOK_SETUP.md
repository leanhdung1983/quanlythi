# Manual Facebook content planner

The **Nội dung Facebook** page is available to administrators at `#/admin/social`. It helps prepare daily content for [Luyện Toán Thông Minh](https://www.facebook.com/luyentoanthongminh/). It does not require a Facebook token or Cron Job and does not publish anything to Meta.

1. Search the question bank and select 1–30 questions with IDs present in `id6_metadata`. Questions with fewer previous uses appear first.
2. Set the first day/time, the interval in days, and a caption template. `{NGAY}`, `{ID}` and `{CHUDE}` are filled automatically. Captions are generated by rules, not by AI.
3. Review each rendered question and caption. Edit the caption if needed, optionally upload a PNG/JPEG under 5 MB, and save. The question preview can be used to make a screenshot when no image was uploaded.
4. Copy the caption, open the Facebook Page and post manually. Only after posting, click **Tôi đã đăng**. The question's `used_count` increases once; repeated clicks do not increase it again.

The schedule is an editorial plan, not a publishing trigger. Time is displayed in Vietnam time. Uploaded images live in MySQL, not the ephemeral Render filesystem.

The earlier automatic publisher is now disabled unless `FACEBOOK_AUTO_POST_ENABLED=1` is explicitly configured. Do not enable it or create a Render Cron Job for this manual workflow. A token alone will not activate auto-posting. Existing approved auto-post records, if any, remain paused until an administrator decides how to handle them.
