Phương Trình Lượng Giác Cơ Bản

Chinh phục phương pháp giải 4 dạng phương trình cốt lõi: $\sin x = m$, $\cos x = m$, $\tan x = m$, $\cot x = m$. Khám phá bản chất hình học của các họ nghiệm trên đường tròn lượng giác, điều kiện có nghiệm $|m| \le 1$ và kỹ thuật đếm nghiệm trên đoạn!

01

Phương Trình $\sin x = m$

Tung độ của điểm biểu diễn trên đường tròn lượng giác:

$$\text{Điều kiện có nghiệm: } |m| \le 1 \quad (-1 \le m \le 1)$$ $$\text{Nếu } |m| > 1 \implies \text{Phương trình vô nghiệm!}$$

Khi $|m| \le 1$, giả sử $\sin \alpha = m$, công thức nghiệm là:

$$\left[\begin{array}{l} x = \alpha + k2\pi \\ x = \pi - \alpha + k2\pi \end{array}\right. \quad (k \in \mathbb{Z})$$

Các trường hợp đặc biệt:

$$\sin x = 0 \iff x = k\pi \quad (k \in \mathbb{Z})$$ $$\sin x = 1 \iff x = \frac{\pi}{2} + k2\pi \quad (k \in \mathbb{Z})$$ $$\sin x = -1 \iff x = -\frac{\pi}{2} + k2\pi \quad (k \in \mathbb{Z})$$
Ký hiệu $\arcsin$: Nếu $m$ không thuộc bảng góc đặc biệt, ta viết $x = \arcsin m + k2\pi$ hoặc $x = \pi - \arcsin m + k2\pi$.
02

Phương Trình $\cos x = m$

Hoành độ của điểm biểu diễn trên đường tròn lượng giác:

$$\text{Điều kiện có nghiệm: } |m| \le 1 \quad (-1 \le m \le 1)$$ $$\text{Nếu } |m| > 1 \implies \text{Phương trình vô nghiệm!}$$

Khi $|m| \le 1$, giả sử $\cos \alpha = m$, công thức nghiệm đối xứng qua trục hoành:

$$x = \pm \alpha + k2\pi \quad (k \in \mathbb{Z})$$

Các trường hợp đặc biệt:

$$\cos x = 0 \iff x = \frac{\pi}{2} + k\pi \quad (k \in \mathbb{Z})$$ $$\cos x = 1 \iff x = k2\pi \quad (k \in \mathbb{Z})$$ $$\cos x = -1 \iff x = \pi + k2\pi \quad (k \in \mathbb{Z})$$
Ký hiệu $\arccos$: Nếu $m$ không thuộc bảng góc đặc biệt, ta viết $x = \pm \arccos m + k2\pi$.
03

Phương Trình $\tan x = m$ & $\cot x = m$

Vì tập giá trị của $\tan$ và $\cot$ là toàn bộ $\mathbb{R}$, nên hai phương trình này luôn có nghiệm với mọi số thực $m$:

$$\tan x = m \iff x = \alpha + k\pi \quad (\text{với } \tan \alpha = m, k \in \mathbb{Z})$$ $$\cot x = m \iff x = \alpha + k\pi \quad (\text{với } \cot \alpha = m, k \in \mathbb{Z})$$

Các trường hợp đặc biệt:

$$\tan x = 0 \iff x = k\pi, \quad \tan x = 1 \iff x = \frac{\pi}{4} + k\pi$$ $$\cot x = 0 \iff x = \frac{\pi}{2} + k\pi, \quad \cot x = 1 \iff x = \frac{\pi}{4} + k\pi$$
Chú ý chu kì: Họ nghiệm của $\tan x = m$ và $\cot x = m$ cộng đuôi $+k\pi$, trong khi $\sin x = m$ và $\cos x = m$ cộng đuôi $+k2\pi$!
04

Phương Pháp Giải Quy Về Cơ Bản

Chiến thuật chuyển hoá các bài toán phức tạp về phương trình cơ bản:

$$\sin f(x) = \sin g(x) \iff \left[\begin{array}{l} f(x) = g(x) + k2\pi \\ f(x) = \pi - g(x) + k2\pi \end{array}\right.$$ $$\cos f(x) = \cos g(x) \iff f(x) = \pm g(x) + k2\pi$$ $$\tan f(x) = \tan g(x) \iff f(x) = g(x) + k\pi \quad (\text{với điều kiện xác định})$$

Kỹ thuật đặt ẩn phụ:

Phương trình bậc hai đối với một hàm số lượng giác: $a \sin^2 x + b \sin x + c = 0$. Đặt $t = \sin x$ với điều kiện $|t| \le 1$.

Ứng dụng thực tế: Giải phương trình xác định thời điểm ca bin vòng đu quay đạt độ cao cho trước hoặc tính góc bắn của pháo binh để trúng mục tiêu!
